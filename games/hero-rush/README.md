# 히어로러시 - 화면/버튼/스테이지 배경 수정본

기존 `lhjfirstsite/games/hero-rush/` 폴더를 이 폴더로 통째로 교체하세요.

## 핵심 수정

- 시작 화면이 어두워지던 원인인 숨김 모달 오버레이 문제 수정
- `[hidden] { display:none !important; }` 적용
- 시작 화면을 모바일 브라우저의 실제 표시 영역 전체에 출력
- 좌우 검은 여백 없이 `cover` 방식으로 표시
- 투명 클릭 영역 대신 실제로 보이고 눌리는 게임 시작 버튼 적용
- 게임 시작 버튼을 누르면 로비로 이동
- 스테이지 1 배경을 탕탕특공대처럼 단순한 초원 스타일로 변경
- 조이스틱 이동, 카메라, 캐릭터 이동 애니메이션 유지

GitHub Pages 반영 후 기존 화면이 보이면 브라우저 캐시를 지우거나 탭을 완전히 닫고 다시 접속하세요.
