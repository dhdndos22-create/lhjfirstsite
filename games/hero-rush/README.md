# 히어로러시 모바일 화면 맞춤 수정본

기존 `lhjfirstsite/games/hero-rush/` 폴더를 이 폴더로 통째로 교체하세요.

## 수정 내용

- iPhone Safari/Chrome의 실제 표시 영역(`visualViewport`)을 기준으로 높이를 계산합니다.
- 주소창과 하단 브라우저 도구막대 때문에 화면 아래가 잘리는 문제를 수정했습니다.
- 시작 화면과 로비 화면의 853×1844 원본 비율을 유지합니다.
- 화면 비율이 다를 때는 검은 여백을 허용하여 이미지와 버튼이 절대 잘리지 않게 했습니다.
- 게임 시작 → 로비 → 스테이지 선택 흐름은 그대로 유지됩니다.

GitHub Pages에 올린 뒤 캐시가 남아 있으면 새로고침하거나 브라우저 탭을 닫고 다시 열어 주세요.
