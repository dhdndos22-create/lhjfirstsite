# 히어로러시 - 전투 캐릭터 디자인/크기 수정본

기존 `lhjfirstsite/games/hero-rush/` 폴더를 이 폴더로 통째로 교체하세요.

## 변경 내용

- 전투 캐릭터를 시작 화면 중앙 검사와 같은 콘셉트로 다시 제작
- 갈색 뾰족머리, 붉은 목도리, 검은 갑옷, 금색 장식 적용
- 은색 검과 파란 방패 적용
- 기존 전투 캐릭터보다 약 35~40% 축소
- 화면 중앙을 가리지 않도록 캐릭터 크기 58×74px로 조정
- 대기/걷기/다리/검 흔들림 애니메이션 유지
- 좌우 방향 전환 유지
- 캐릭터 체력바와 이름 위치도 작은 크기에 맞게 조정
