# 히어로러시 모바일 화면 전체 수정본

기존 `lhjfirstsite/games/hero-rush/` 폴더를 이 폴더로 통째로 교체하세요.

## 수정 내용

- 시작 화면과 로비 이미지를 `cover`가 아닌 `contain` 방식으로 표시하여 위·아래가 잘리지 않게 수정
- 남는 좌우 공간은 같은 배경의 블러 이미지로 채워 화면이 비어 보이지 않게 처리
- 시작/로비 버튼을 화면 퍼센트가 아니라 원본 이미지 좌표(853×1844)를 기준으로 계산
- 휴대폰 화면 비율, 주소창 높이, 회전, 리사이즈가 바뀌어도 버튼 위치를 다시 계산
- 게임 시작, 메인으로, 설정, 통합 메뉴, 입장하기 버튼의 실제 이미지 위치와 터치 영역 일치
- 입장하기 버튼이 기존보다 위쪽 실제 위치에 맞도록 수정
- iPhone Safari의 실제 보이는 화면 높이에 맞게 `visualViewport` 대응 유지
- 캐시 갱신 버전을 `20260730-3`으로 변경

GitHub 업로드 후 Safari에서 이전 파일이 보이면 탭을 닫고 다시 접속하거나 페이지를 새로고침하세요.
